# Three colour variations

The site ships with three baked colour identities. The repository source is
canonical **mono** (black and white); the other two are generated by a
single script.

| Variant | Ground | Surfaces | Text | Accent |
|---|---|---|---|---|
| **mono** | #000000 | #161616 / #222222 | #F7F7F5 / #9D9D9D | #FFFFFF |
| **lagoon** | #0B2320 | #0F2F2A / #16403A | #EDF2E9 / #A6BCB3 | #7FD8B8 |
| **slate** | #0B1322 | #101A30 / #182645 | #F2F5FB / #A9B4C9 | #8FB8E8 |

- **mono** — the black-and-white brand look: pure black page, layered
  grays, white accent. The current live site.
- **lagoon** — deep green-teal studio with sea-glass mint accents and bone
  text; calm, botanical, clinical-fresh.
- **slate** — deep navy with ice-blue accents; precision and trust, a cool
  professional register.

Accent drives CTAs, eyebrows, icons, tables and hover states. Photography
and the film render in grayscale in all three (matching the mono identity);
the palette colours live in the UI layer.

## Build all three

```bash
bun install
bash scripts/fetch-public-assets.sh   # restores media from the live site
bash scripts/build-variants.sh       # creates dist-static-mono / -lagoon / -slate
```

Each output folder is a complete installable site, including its own
`.htaccess` (Apache routing for GoDaddy shared hosting) and
`robots.txt`/`sitemap.xml`.

## Install one variant on GoDaddy

- **Shared hosting (cPanel):** upload the contents of your chosen
  `dist-static-<variant>/` folder into `public_html` (zip it, then Extract
  in File Manager). Done.
- **VPS (SSH):** copy the chosen folder to `/var/www/invisible-aligners`
  (`cp -r dist-static-<variant>/. /var/www/invisible-aligners/`) and point
  Apache or nginx at it (see nginx.conf / install-godaddy.sh).

## Changing the default variant in source

Edit the palette tokens in `src/styles.css` (the `@theme` block), the film
stage theme in `src/scroll-scrub-scenes.tsx`, the browser theme color in
`src/routes/__root.tsx` and `public/site.webmanifest`, then rebuild.
`build-variants.sh` automates exactly this for the three variants.
